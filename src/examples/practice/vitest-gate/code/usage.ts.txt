// --- 5. pre-commit 与 CI 的分工 ---

//! pre-commit（husky + lint-staged）：只跑改动文件的 lint/format，快
//! pre-push：可选跑 type-check
//! CI：全量类型 + 代码检查 + 测试 + 构建 + 体积，慢但完整
//! 别把全量测试塞进 pre-commit，开发者会绕过（--no-verify）

// --- 踩坑清单 ---

//! 1. 本地 Windows、CI Linux：文件名大小写不一致会挂
//! 2. 锁文件没提交 / 用了 npm install：依赖版本漂移
//! 3. 只跑测试不跑构建：类型错误（vue-tsc -b）会漏到线上
//! 4. 首屏包体悄悄变大：靠体积门禁，不靠人盯构建日志
//! 5. 快照测试跨平台换行符差异：配置 snapshotFormat 或统一 LF
//! 6. CI 里忘了设置环境变量：测试访问不到接口，随机失败

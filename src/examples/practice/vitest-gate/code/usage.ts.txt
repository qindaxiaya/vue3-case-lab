//! CI：全量 lint + 类型 + 测试 + 构建，慢但完整
//! 别把全量测试塞进 pre-commit，开发者会绕过（--no-verify）

//! 本项目踩过的坑：单测用内联假数据，绕过了「glob 收录案例」的真实逻辑，

// --- 踩坑清单 ---

//! 1. 本地 Windows、CI Linux：文件名大小写不一致会挂
//! 2. 锁文件没提交 / 用了 npm install：依赖版本漂移
//! 3. 覆盖率阈值定太高没人维护，定太低没意义；先跑一遍看基线再定
//! 4. 快照测试跨平台换行符差异：配置 snapshotFormat 或统一 LF
//! 5. 只跑测试不跑构建：类型错误（vue-tsc -b）会漏到线上
//! 6. CI 里忘了设置环境变量：测试访问不到接口，随机失败
//! 7. 用 --max-warnings 0：警告也要当错误，否则会越积越多
